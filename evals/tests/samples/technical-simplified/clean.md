# The clean sample

This document gives the linter a text that obeys the rules.

Install the dependencies, then run the tests. When the tests pass, commit the
change. The test suite is deterministic, and the suite runs without the
network.

- Keep the functions small.
- Write one topic per paragraph.

The linter reads the rule file, and the linter reports each violation. Thus
the fidelity gate stays mechanical. The gate can reject a pair, and the run
manifest records the decision.
